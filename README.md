# Brian Angaluki | Portfolio

My personal portfolio: a single-page site built with plain HTML, CSS and JavaScript.

## Run it locally

Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Structure

```
portfolio/
├── index.html
├── css/style.css
├── js/main.js
└── assets/          (add photo.jpg and resume.pdf here)
```

## Deploy

Pushed to GitHub and deployed on Vercel. Every push to `main` redeploys automatically.
